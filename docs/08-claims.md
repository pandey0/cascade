# 08 Claims boundary
| Milestone public | Wording |
|---|---|
| Benchmark published | "Built a calibrated decision cascade; on <tasks> it reduced cost by X% at Y% agreement with the teacher (CI, scripts public)" |
| Gateway public | "Open-sourced a drop-in decision gateway with shadow mode and audit logs" |
Never claim: users, customers, revenue, 'guaranteed accuracy', production use, or Jev benchmark numbers as your own. List LangChain/LangGraph/Jev as skills only after a public repo uses them.
